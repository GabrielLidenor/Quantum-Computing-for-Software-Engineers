# Bits to Qubits: Quantum Computing for Software Engineers

Quantum computing is rapidly capturing global attention due to risks in cryptography, national security implications, and groundbreaking simulation capabilities.

The goal of this repository is simple: to guide software engineers like you and me on the journey to becoming Quantum Software Engineers.

We bridge the gap between heavy academic theory and practical software development. Step by step, we will cover everything from linear algebra and probability to quantum mechanics. Every math and physics concept will be translated directly into runnable Python and Qiskit code.

```
Prerequisite: This project is not a tutorial on basic Python. Prior programming experience and familiarity with standard software engineering concepts is required.
```

### Core References

All concepts are grounded in foundational academic literature, including:

- Introduction to Quantum Mechanics by David J. Griffiths & Darrell F. Schroeter

- Quantum Mechanics: The Theoretical Minimum by Leonard Susskind & Art Friedman

- Quantum Computation and Quantum Information by Michael A. Nielsen & Isaac L. Chuang

- Quantum Computing for Computer Scientists by Noson S. Yanofsky & Mirco A. Mannucci
